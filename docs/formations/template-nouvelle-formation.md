> Source : document Claude Docs « Template — Nouvelle formation » (https://claude.ai/artifact/MDistFsUsGfVxieNb12XHp), créé le 29/09/2026. Copie versionnée dans le dépôt — dupliquer ce fichier (ou le document en ligne) pour chaque nouvelle formation.

## Comment utiliser ce document

Un exemplaire de ce template par nouvelle formation à ajouter au catalogue du site. Remplissez chaque partie avec vos propres mots, aucun jargon technique n'est nécessaire — les exemples entre crochets sont juste là pour vous guider, à effacer et remplacer.

Une fois complété, envoyez ce document à la personne qui publie sur le site (voir [Cookbook — Publier une formation](./cookbook-publier-une-formation.md) pour la suite du processus). Elle transformera votre contenu en fiche publiée, sans rien y ajouter ni inventer : ce que vous écrivez ici est ce qui sera repris.
